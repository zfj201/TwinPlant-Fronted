# TwinPlant-Fronted

Vue 3 and TypeScript frontend for TwinPlant.

```sh
npm install
npm run dev
```

Run `npm run build` to type-check and create the production build.

| Directory | Responsibility |
| --- | --- |
| `src/layouts/` | Shared page layout |
| `src/view/` | Page-level components |
| `src/three/` | Future Three.js scene and 3D assets integration |
| `src/services/` | Future MQTT client and message handling |
| `src/stores/` | Future shared state for devices and connectivity |
